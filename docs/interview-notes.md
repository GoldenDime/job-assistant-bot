# Интервью: заметки и сводка

Скрипт — в Claude Doc «AI-бот для соискателей: бюджет и интервью». Сюда — только обезличенные заметки (Р1, Р2…), без имён и контактов.

## Карточка на одно интервью (копировать для каждого)

```
Респондент: Р_ | дата: __.__.2026 | роль/кого ищет: ____ | ищет работу: __ мес.
Откликов за месяц: __ | ответов: __
Время на один отклик: __ мин
Адаптирует резюме под вакансию: да / нет / иногда — почему: ____
Пробовал LLM/сервисы: ____ | что раздражало: ____
Топ-3 боли (его словами):
1. «____»
2. «____»
3. «____»
Реакция на идею бота: ____ | чему не поверит: ____
Что важнее: готовое резюме / список правок / сопроводительное
Платил за помощь в поиске: ____ (сколько, за что)
Согласен тестировать: да / нет | готов дать резюме в эталонные пары (обезличенно): да / нет
```

## Сводка (заполнить после 3–4 интервью)

| Вопрос | Р1 | Р2 | Р3 | Р4 | Вывод |
|---|---|---|---|---|---|
| Адаптирует резюме под вакансию? | | | | | |
| Минут на отклик | | | | | |
| Главная боль | | | | | |
| Пробовал LLM, что не так | | | | | |
| Нужнее: резюме / правки / сопроводительное | | | | | |
| Платил за помощь | | | | | |
| Готов тестировать | | | | | |

**Решение по сценарию MVP:** оставить «адаптация резюме» / сменить на ____ — потому что ____.

Критерий «боль подтверждена» (задан до интервью): минимум 3 из 4 тратят на отклик больше 10 минут **или** уже пробовали адаптировать резюме через LLM и были недовольны результатом.
