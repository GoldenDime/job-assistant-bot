# План пилота (20–30 пользователей, 2 недели)

## Цели и метрики (заданы до запуска, чтобы не подгонять)

| Метрика | Как считаем | Ориентир для решения |
|---|---|---|
| Активация | result_exported / bot_started | < 30% → чиним онбординг до итерации по качеству |
| Отвал на резюме | resume_uploaded / bot_started | < 60% → смотреть resume_parse_failed по форматам |
| Качество | средний rating в feedback_given; revision_requested на генерацию | rating < 3,5 или > 0,5 переделки → правим промпт |
| Честность | доля генераций с faithfulness_flags > 0 | > 10% → ужесточаем промпт, проверяем руками |
| Возврат | return_session / активированные | справочно: на 2 неделях выборка мала |
| Себестоимость | Σ cost_usd / активированные | для юнит-экономики |

Ориентиры — гипотезы, не цели. На 20–30 пользователях разница меньше 10–15 п.п. — шум, выводы формулируем осторожно.

## Привлечение

Deep-link с меткой источника: `https://t.me/<бот>?start=<источник>` — источник уходит в `bot_started.source`.

| Канал | Метка | Ожидание |
|---|---|---|
| Участники интервью и их рекомендации | `interview` | 5–8 |
| Однокурсники, команда хакатона | `friends` | 5–10 |
| Чаты джунов / перехода в IT (с разрешения админов) | `chat_<название>` | 10–20 |

## Ход пилота

1. День 0: бот на VPS, `LLM mode: real` в логе, прогон evals на flash, сам прохожу сценарий на 3 своих вакансиях.
2. Дни 1–7: привлечение, ежедневно смотрю ошибки (`generation_failed`, `resume_parse_failed`) и чиню блокеры.
3. День 7: отчёт `reports.unit_economics`, выбор ОДНОГО изменения по самому большому отвалу воронки.
4. Дни 8–14: изменение выкачено (bot_version 0.2.0), сравнение воронки до/после.
5. День 14: финальный отчёт, README с реальными цифрами, формулировки для резюме.

## Итерация

Одно изменение за раз, версия в `bot/analytics.py: BOT_VERSION`, чтобы сравнивать когорты до и после.
