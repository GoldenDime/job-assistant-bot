# AI-ассистент для соискателей

Telegram-бот, который адаптирует резюме под конкретную вакансию на базе LLM (DeepSeek) и честно показывает пробелы: чего из требований вакансии в резюме нет.

**Статус:** в работе (ноябрь–декабрь 2026). Результаты пилота и юнит-экономика появятся здесь после запуска на реальных пользователях. Никаких цифр до этого момента.

## Продуктовые вопросы

1. Решает ли бот реальную боль соискателя? Проверяем интервью до MVP.
2. Где отвал в воронке активации? Меряем событиями в Amplitude.
3. При какой цене продукт окупает инференс? Себестоимость считаем по токенам из каждого запроса.

## Сценарий MVP

`/start` → резюме (PDF, DOCX, TXT или текст) → текст вакансии → адаптированное резюме + что изменено + пробелы → скачать / переделать / оценить.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать токен бота и ключ DeepSeek
python -m bot.main
pytest
```

## Стек

Python 3.11+, aiogram 3, DeepSeek API (OpenAI-совместимый), Amplitude HTTP API.
