# Эталонные пары

`pairs.jsonl` — стартовый набор из 6 синтетических пар «резюме + вакансия» (люди и компании выдуманы). У каждой пары:

- `must_keywords` — требования вакансии, которые в резюме **есть**: хорошая адаптация должна их подсветить;
- `forbidden` — требования, которых в резюме **нет**: если они появились в адаптированном резюме, модель приписала опыт.

Цель — 20–30 пар. Новые пары добавляем из реальных резюме участников интервью и пилота **только с их согласия** и после обезличивания.

Запуск: `python -m evals.run_eval --models deepseek-flash deepseek-v4-pro`. Без ключа — `LLM_MODE=mock`, это проверяет только харнесс, качество мока смысла не имеет. Результаты пишутся в `evals/results/` (CSV в git не коммитим, кроме итогового).
